# IBM Applied Data Science Capstone Project

## 🚀 Project Overview
This capstone project analyzes SpaceX Falcon 9 launch data to predict whether the first stage of the rocket will successfully land. By leveraging data collection, SQL queries, interactive visualizations, Folium maps, Plotly Dash dashboards, and Machine Learning classification models, this project identifies the key factors influencing booster landing success.

## 📁 Repository Structure
- `jupyter-labs-spacex-data-collection-api(2).ipynb`: Data collection via SpaceX REST API.
- `jupyter-labs-webscraping.ipynb`:Web Scraping.
- `labs-jupyter-spacex-Data wrangling.ipynb`:Data wrangling, Data cleaning, preparation
- `jupyter-labs-eda-sql-coursera_sqllite.ipynb`: Exploratory Data Analysis using SQLite and SQL queries.
- `edadataviz.ipynb`: Visual analysis using Matplotlib and Seaborn.
- `lab_jupyter_launch_site_location.ipynb`: Interactive geographical analysis of launch sites.
- `6_dash_app.py`: Interactive Plotly Dash web application for launch analytics.
- `SpaceX_Machine Learning Prediction_Part_5.ipynb`: Model training, hyperparameter tuning (GridSearchCV), and evaluation (Logistic Regression, SVM, Decision Tree, KNN).
